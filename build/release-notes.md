## v2.0.1-beta

首个 beta 版：新增应用内自动更新，并修复多项稳定性问题。

- 应用内自动更新：支持 beta / 正式双通道，检查、下载、安装一步到位
- 更新弹窗展示新版本号、完整更新说明、下载进度与速度
- 下载完成后可一键「更新并重启」，也可后台下载
- 更新改为静默安装，不再弹安装向导（首次安装仍可选择安装目录）
- 修复切换更新通道后返回首页、按 Ctrl+R 刷新白屏的问题
- 修复更新时提示「Failed to uninstall old application files: 2」的问题
- 修复安装时误报「有谱无法关闭，请手动关闭它」的问题
- 修复同通道旧版本被误提示为可更新的问题（不再出现降级提示）
- 修复「正式版」通道误拉取 beta 更新元数据的问题
