正式版发布：全新的沉浸歌词皮肤系统，以及更完整的沉浸页操作。

• 新增：「倾诉」「流光」「浮名」三套沉浸歌词主题，与原有「经典」并存，顶部胶囊一键切换
• 新增：三套主题各自拥有独立设置（外观 / 歌词 / 背景 / 字体 / 关于），背景与字体按主题分别保存
• 新增：逐歌主题配色与逐词配色——配色跟着当前歌曲与封面走，关键词随专辑主色变化
• 新增：多种沉浸背景——Common / Monet / Nomand / Latent / Sora / 自定义 URL，以及「几何」动态背景
• 新增：副字幕显示罗马音与译文，可选择保留哪些内容
• 新增：沉浸页方向键操作——← / → 调整进度 5 秒，↑ / ↓ 调整音量 5%
• 新增：沉浸页可显示实时帧率
• 优化：鼠标静止后自动隐藏光标；操作控制条时不自动收起
• 优化：底栏高度 88 → 72px，沉浸页控制条 90 → 76px
• 修复：浮名 Common 背景白屏、四边出现矩形边界
• 修复：开启背景模糊后覆盖背景出现白边
• 修复：浮名原生背景遮挡进度条
• 修复：浮名拖动窗口时画面瞬移、副歌词换行抖动
• 修复：逐词配色在真实歌曲上为空
• 变更：后端不再单独在线更新，随应用一起更新；修复更新后后端无法启动的问题
• 安全：后端日志中的登录凭据与手机号在落盘前统一脱敏
