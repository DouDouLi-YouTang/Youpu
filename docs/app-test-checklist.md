## 1. 音频通路（最高风险）

改了什么：音频从「主进程隐藏引擎窗口」改回渲染进程的 `<audio>`；移除低内存模式；
`<audio>` 被**无条件**设了 `crossOrigin = 'anonymous'`；打开沉浸页时会建 Web Audio 图。

### 1.1 三种音源都要能播（对应 `crossOrigin` 的全局影响）

`crossOrigin='anonymous'` 是全局生效的：某个音源如果响应缺 `Access-Control-Allow-Origin`，
后果不是「没频谱」而是**彻底加载失败**。三处音源已于改造中核实/补齐，但要以实机为准：

| # | 场景 | 预期 |
|---|---|---|
| 1 | 在线播放（未下载的歌，走网易云 CDN 直链） | 有声；进度条走动；不出现 media 加载错误 |
| 2 | 播放已下载到本地的歌（`muice-file://`） | 同上 |
| 3 | 播放命中缓存的歌（`muice-cache://`，**主路径**） | 同上 |

**怎么看失败**：Console 里会有 `Cross-Origin Resource Sharing` / `MEDIA_ELEMENT_ERROR` 之类，
且**歌直接放不出来**（不是静音、是加载失败）。任何一条失败都要立刻停下来报给我。

### 1.2 建图前后的行为一致（`createMediaElementSource` 是不可逆的）

Web Audio 图在**第一次打开沉浸页**时建立（普通列表页不建）。元素一旦进图，声音只从图里出来。

| # | 操作 | 预期 |
|---|---|---|
| 4 | 普通页面播放 → 进沉浸页 | 声音**不中断**，不静音，不重头开始 |
| 5 | 沉浸页里：暂停 / 播放 / 切歌 / 拖进度条 / 点歌词 seek | 全部正常，无静音、无爆音、无加速减速 |
| 6 | 沉浸页 → 退出到普通页面 | 声音继续，不中断 |
| 7 | 连续开关沉浸页 5 次以上 | 仍然有声（幂等，不应出现第二次建图失败） |

### 1.3 输出设备切换（建图前 / 建图后走的是两条不同路径）

| # | 操作 | 预期 |
|---|---|---|
| 8 | **未打开过沉浸页**时切换输出设备（设置里的播放设备） | 声音从新设备出 |
| 9 | 打开沉浸页（建图完成）后切换输出设备 | 声音从新设备出（走 `AudioContext.setSinkId`） |
| 10 | 再退出沉浸页，切回又一个设备 | 仍从新设备出（设备选择在两条路径间不丢） |
| 11 | 切到一个「已拔出的设备 / 不存在的设备」 | 不崩溃；要么回退要么提示，不能整个应用没声音 |

> 若第 8–10 项某一项失败：告诉我「当时是否打开过沉浸页」，这能直接定位是
> `HTMLMediaElement.setSinkId` 路径还是 `AudioContext.setSinkId` 路径。

### 1.4 低内存模式确认移除

| # | 操作 | 预期 |
|---|---|---|
| 12 | 沉浸设置面板逐个 tab 翻一遍 | **不再有**「低内存模式」相关开关 |
| 13 | 播放中打开任务管理器 | 不应再有额外的隐藏渲染窗口/主进程引擎残留；CPU 占用没有异常翻倍 |

### 1.5 已知情况（**不是 bug**，别当缺陷报）

- **频谱现在唯一的消费者是「几何」背景。** `AudioBands`（真实频谱）已在皮肤上下文里就绪
  （`SkinContext.bands()`），但两款皮肤都还没用它画东西 —— 只有背景类型选「几何」时，
  形状才会按频带缩放（见 §6）。其余背景下 Web Audio 图仍是「建好、暂无消费者」。
  也就是说：**不选「几何」背景时，第 1 节建的图是白建的**，这是当前预期状态。

## 4. 「倾诉」面板（新功能）

> **这一节刚大改过（2026-10-10）**：首版把 Folia 的排版算法套在了经典的「左封面 + 右歌词」
> 双栏骨架上，看起来像「经典面板换了首歌」。现在改成了 Folia 真正的形态 ——
> **全屏歌词舞台，没有封面列**。第 24–27、35–39 条是这次重点。

| # | 操作 | 预期 |
|---|---|---|
| 24 | 有逐字歌词的歌（多数歌走 YRC，都有） | 当前行按 1–4 段分行排布，**整屏居中**（不是挤在右半边）；每段各自浮现 |
| 25 | 配色 | **其中一段（随机但每首歌可复现）是专辑主色**、斜体 + 上下交错；其余段近白色正体。换歌/换封面时那个颜色跟着变 |
| 26 | 逐字节奏 | 正在唱的字有轻微放大脉冲；唱过的字留一点「余晖」（略大且不回落为 0） |
| 27 | 底部副字幕 | 底部小字显示**罗马音（在前）+ 译文（在后）**，缺哪条就少一行、**不出现空行**；拖动设置面板「歌词」tab 里罗马音 / 译文两个滑块，两行字号**各自**跟着变（经典面板也变）。注意：同一首歌同一滑块值下，本面板译文绝对 px **比经典面板小**（本面板正文约 90px、副字幕走 Folia 的 20px 档，经典面板正文 32px、译文同倍），这是设计如此 |
| 28 | 暂停 | 动画**定格**（不能继续跑、也不能全部消失） |
| 29 | 恢复播放 | 从定格处继续，不跳帧、不重播整行 |
| 30 | 拖进度条到别处 / 切歌 | 立刻重排到当前行；**不能卡在上一行** |
| 31 | 歌词偏移（设置里调 `lyricOffset`） | 面板跟着偏移，不出现「面板比声音早/晚一行」的错位 |
| 32 | 点某一段歌词 | 跳到该行（seek 正确；偏移量与经典面板一致） |
| 33 | 长行（**横向**超过可用宽度） | 整体缩小以放下（最多缩到 50%/55%）；**极长**时改为重切成更多段 |
| 34 | 窗口缩放 | 字号随视口变化（clamp）；缩放后面板不溢出屏幕 |
| 34b | **纵向放不下**（窗口高度压到最小 640、或字号设置拉到 64、或长句被切成 4 段） | 字号整体再缩一档，**首尾段都完整可见**，不退化成裁切。这是本项目在 Folia 之外补的一层（Folia 只做横向，矮窗口下会切掉首尾段） |
| 35 | **「经典」与「倾诉」互切** | 两个面板骨架完全不同（一个双栏带封面、一个全屏无封面），不是同一套布局换色 |
| 36 | 「全部」/「仅歌词」模式 | 「倾诉」都是全屏歌词，**不显示封面**（这是刻意的，对齐 Folia） |
| 37 | 「仅封面」模式 | 整屏让给封面；封面水平/垂直对齐四组设置都生效（**居中要真的居中**） |
| 38 | 演唱者/贡献者行 | 「倾诉」有意不渲染贡献者（设计如此），确认不会出现半截元素 |
| 39 | 无歌词 / 纯音乐 / 加载中 / 未选歌 | 分别显示：`歌词加载中…` / `纯音乐，请欣赏` / `暂无歌词` / `等待音乐` |
| 40 | 字号设置（`lyricFontSize`）与自定义字体 | 倾诉面板跟着变（字号、字体族都吃全局设置；译文行也跟着缩放） |
| 41 | 播放速度 1.5× | **已知限制**：CSS 动画走墙钟时间，不随倍速缩放 —— 逐字脉冲会跟不上（经典面板的逐字过渡同样如此）。不作为缺陷记录 |

### 4.1 与 Folia 的已知差异（**不是缺陷**，别报）

| 项 | Folia | 本项目 | 原因 |
|---|---|---|---|
| 上下交错量 | `±字号/6` | 同 | — |
| 分段浮现 | 逐段依次出现 | 同 | — |
| 副字幕层 | 罗马音 + 译文 + 「下一句预览」 | 罗马音 + 译文（顺序与去重口径同经典面板） | 「下一句预览」未做；要加说一声 |
| 分段参数 | 设置面板可调（倾斜概率等） | 固定为源码默认值（0.35） | 本项目未开放这些旋钮 |
| **纵向溢出** | 只按宽度缩放，段多/窗口矮时首尾段被切 | **多一层高度自适应**：先扣掉段间距，再把字号整体缩到放得下（下限同横向 0.5/0.55） | Folia 的舞台高度是 `70vh` 固定值，本项目舞台吃掉「减去副字幕与控制条后的剩余高度」，必须自适应 |

## 6. 几何背景（新增的第 6 种背景类型）

来源是 Folia 的背景层（`GeometricBackground.tsx`）：底色之上 15 个缓慢漂移自转的几何形状
+ 20 个上浮粒子 + 一层径向暗角。**与 Folia 有三处刻意差异**（不是缺陷）：随机源换成
按歌曲 id 的确定性种子（同一首歌每次进来形状都一样，不会跳）；不做 JS 弹簧，频带缩放走
CSS `transition`；漂移/自转交给 CSS keyframes 而不是逐帧写内联样式。

| # | 操作 | 预期 |
|---|---|---|
| 47 | 设置 →「背景」tab 的「类型」选「几何」 | 立即出现形状与粒子；类型一行现在有 6 个选项（流体/模糊/渐变/**几何**/纯色/无） |
| 48 | 反复「几何」↔「纯色」来回切 5 次 | 每次都正常出画面，不残留、不白屏、控制台无报错 |
| 49 | 切歌 / 重进沉浸页 | 同一首歌形状布局**不变**（确定性种子）；换一首歌才换一套 |
| 50 | 播放时看形状 | 圆/方（低音）、三角（中音）、十字（高音）、图标（整体能量）各自**独立**缩放，随鼓点起伏 |
| 51 | 暂停播放 | 形状缩回静止档（不再随音乐缩放）；漂移与自转**继续**（背景是环境层，定格反而像卡住） |
| 52 | 明暗主题切换（`colorScheme`） | 形状颜色随之翻转（深色下浅、浅色下深），不会出现「白底上看白形状」 |
| 53 | 换歌换封面 | 粒子与暗角颜色跟着专辑主色变 |
| 54 | 窗口缩到很窄 / 拉很大 | 背景铺满、不出现横向滚动条、形状不溢出到可视区外 |
| 55 | 系统开启「减少动态效果」 | 漂移与粒子停止，静态构图仍在（不是整块消失） |
| 56 | 性能 | 与「流体」背景比 CPU/GPU 占用应更低；不支持 `scale`/`translate` 独立属性的旧内核下形状仍在（只是不缩放） |

> 第 50 条需要能听出高低音的歌（鼓点明显的）。若完全不动，先确认背景类型确实是「几何」，
> 再报给我 —— 频带通路的排查要看 `AudioBands`。

### 6.1 与 Folia 的已知差异（**不是缺陷**，别报）

| 项 | Folia | 本项目 | 原因 |
|---|---|---|---|
| 随机性 | `Math.random()`，每次进页面都换一套 | 按歌曲 id 的确定性种子 | 进页面/切皮肤/暂停时形状不该「跳一下」 |
| 频带平滑 | framer-motion `useSpring` | CSS `transition: scale 0.12s linear` | 频带本就每帧刷新，再加 JS 弹簧只是多一层延迟 |
| 形状驱动 | JS 逐帧写内联样式 | CSS keyframes 驱动漂移/自转 | 不与 60fps 流体背景抢性能预算 |
| 暂停行为 | 冻结漂移 | 漂移继续，只有频带缩放回落 | 背景定格看起来像卡住 |
| 暗角末色 | 恒 `rgba(0,0,0,.6)` | `--rnp-accent-color-overlay`（浅色主题下是白） | 浅色主题下用黑色暗角会「白底被压黑一圈」 |
